# Skill Creator

A skill for creating new skills and iteratively improving them.

## Layout

- `SKILL.md` — the skill itself (this directory's instructions)
- `scripts/` — executable Python modules (`python -m scripts.<name>`)
- `eval-viewer/` — `generate_review.py` human review viewer
- `agents/` — subagent instruction files
- `references/` — schemas and supporting docs
- `assets/` — HTML templates
